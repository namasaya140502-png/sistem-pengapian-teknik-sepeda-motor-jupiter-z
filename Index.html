Konsep Dasar Sistem Pengapian

Sistem pengapian merupakan salah satu komponen utama mesin sepeda motor yang bertanggung jawab menghasilkan bunga api di ruang bakar. Bunga api diperlukan untuk membakar campuran bahan bakar dan udara sehingga menghasilkan tenaga untuk menggerakkan sepeda motor.

Pengapian ACSumber listrik pengapian berasal langsung dari alternator/generator pembangkit arus AC.
Pengapian DCSumber arus pengapian berasal dari baterai/aki (arus DC).

Materi pada media ini membahas sistem pengapian Jupiter Z berarus DC. Pada sistem ini, stator coil terdiri atas kumparan penerangan dan kumparan pengisian.

Istilah penting

  • DC (Direct Current): arus searah.
  • Timing pengapian: waktu terjadinya pengapian yang ditentukan berdasarkan posisi mesin.
  • Wiring diagram: diagram jalur kabel dan hubungan komponen kelistrikan.

Alur Cara Kerja Sistem Pengapian

Ringkasan urutan kerja berdasarkan materi yang dipelajari:

Poros engkol berputar→Rotor magnet berputar→Stator menghasilkan arus→Regulator/rectifier
Baterai & kunci kontak→CDI menyimpan muatan→Pick up coil memberi sinyal timing
CDI melepas muatan→Ignition coil menaikkan tegangan→Busi memercikkan bunga api

Penjelasan

  1. Poros engkol dan rotor magnet berputar, sehingga stator coil menghasilkan arus listrik.
  2. Arus menuju regulator/rectifier untuk distabilkan, kemudian arus DC diteruskan ke kunci kontak dan baterai.
  3. Arus DC diteruskan ke CDI dan disimpan pada kapasitor.
  4. Pick up coil memberi sinyal untuk menentukan timing. CDI kemudian melepas muatan menuju ignition coil.
  5. Ignition coil memperbesar tegangan dan mengirimkannya ke busi melalui kabel tegangan tinggi.
Diskusi: Mengapa timing pengapian harus tepat? Jelaskan hubungan sinyal pick up coil, CDI, ignition coil, dan busi.

Praktikum Pemeriksaan Sistem Pengapian

Alat dan bahan

  • Unit sepeda motor
  • Tools box
  • Multitester
  • Nampan dan majun
  • Buku manual
  • Feeler gauge
  • Ignition checker

Keselamatan kerja

  1. Gunakan pakaian praktik.
  2. Gunakan alat sesuai fungsi dan spesifikasinya.
  3. Jaga kebersihan tempat praktik.
  4. Tandai komponen sebelum pembongkaran untuk memudahkan perakitan.
  5. Ikuti prosedur dan tanyakan kepada instruktur jika ragu.
  6. Hindari kehilangan alat/komponen dan catat hasil pemeriksaan.
  7. Ikuti instruksi guru/instruktur.
